# anton-flows-sandbox

A small public test repository for [son-of-anton](https://github.com/ChristianNorbertBraun/son-of-anton)
workflows (the "anton flows" conductor). Issues, branches and pull requests here are created by
experiments and may be closed or deleted at any time.

Run the checks:

```sh
python3 -m compileall -q textkit tests   # "lint"
python3 -m unittest discover -s tests    # tests
```
